# Acknowledgements

Bicho for Astro wraps the [Bicho JavaScript SDK](https://github.com/bicho-fyi/bicho-javascript) (Apache-2.0) and integrates with [Astro](https://astro.build/) via its official integration and middleware hooks.

Runtime and development dependencies retain their own licenses and are installed through npm. No OpenTelemetry schema files or Sentry implementation are vendored in this package.
